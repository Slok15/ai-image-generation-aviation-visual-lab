# AI Image Generation – Aviation Visual Lab

## 📌 About the Project

This repository contains the **Day 4 & Day 5 AI Image Generation – Aviation Visual Lab** for the **BBA Aviation Management** program.

The lab focuses on using Generative AI tools to create realistic aviation-related visuals, compare outputs from different AI image-generation tools, and understand how detailed prompts influence image composition, lighting, realism, and consistency.

---

## 🎯 Objectives

* Create aviation visuals using Generative AI.
* Compare outputs generated using different AI image tools.
* Understand prompt adherence and visual realism.
* Test spatial instructions such as **camera-left** and **camera-right**.
* Analyse lighting, facial features, hands, backgrounds, uniforms, and unwanted text/logos.
* Understand how prompt wording influences AI-generated visuals.

---

## 🖼️ Activity 1 – Creating an Aviation Scene

A common prompt was used across multiple AI image-generation tools.

### Prompt Focus

The prompt requested:

* A photorealistic female airline customer-service executive
* Modern international airport check-in counter
* Professional navy-blue uniform
* Soft natural light from camera-left
* Blurred passengers and terminal background
* Realistic skin texture and facial features
* Commercial photography style
* Shallow depth of field
* 16:9 composition
* No airline logos or clearly readable text

The same aviation scene was generated using **Gemini and ChatGPT**.

---

## 🔍 Activity 2 – AI Tool Comparison

The generated visuals were evaluated using different criteria.

| Evaluation Criteria | What Was Analysed                               |
| ------------------- | ----------------------------------------------- |
| Prompt Adherence    | How closely the image followed the instructions |
| Human Realism       | Facial features and natural appearance          |
| Skin Texture        | Realistic or artificial-looking skin            |
| Eyes & Hands        | Distortion or unnatural details                 |
| Airport Setting     | Realistic aviation environment                  |
| Lighting            | Correct direction and softness                  |
| Uniform             | Professional aviation appearance                |
| Text & Logos        | Unwanted readable text or branding              |
| AI Appearance       | Visible signs of AI generation                  |

Both tools generally followed the prompt and created realistic airport environments. The activity also identified differences in lighting, background treatment, and visual realism.

---

## 💡 Activity 3 – Testing Spatial Instructions

The lab tested whether changing spatial instructions could influence the direction of light.

### Camera-Left Prompt

The AI was instructed to create:

> Soft morning light entering from camera-left and illuminating the left side of the scene.

### Camera-Right Prompt

The instruction was then changed to:

> Soft morning light entering from camera-right and illuminating the right side of the scene.

Both prompts maintained other elements such as:

* Airport check-in counter
* Professional ground-staff executive
* Tablet
* Modern airport background
* Realistic facial features
* 16:9 composition
* No logos
* No clearly readable text

---

## 📊 Observation

The experiment showed that spatial prompt instructions can influence the generated lighting direction.

* **Camera-left:** Light entered from the left side.
* **Camera-right:** Light entered from the right side.
* The airport environment remained broadly consistent.
* The subject maintained a professional aviation appearance.
* No major spatial instruction was ignored.

This demonstrates the importance of using precise spatial language when creating AI-generated visuals.

---

## 🧠 Key Learning

The lab demonstrates that **prompt quality directly affects AI-generated visual output**.

Specific instructions about:

* Subject
* Location
* Clothing
* Lighting
* Camera position
* Composition
* Background
* Text and logos

can help produce more controlled and consistent visuals.

A particularly important learning from the lab is that spatial terms such as **camera-left** and **camera-right** can influence lighting and composition in AI-generated aviation visuals.
